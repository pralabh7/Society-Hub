# SocietyHub

A centralized platform designed to streamline student engagement with clubs and societies. SocietyHub enables students to discover societies, explore events, receive announcements, apply for recruitments, and get AI-powered society recommendations based on their interests.

## 🚀 Features

### 👥 Society Management

* Browse all clubs and societies from a single platform
* View society descriptions, objectives, and activities
* Explore ongoing and upcoming events

### 📢 Announcements & Events

* Society coordinators can post announcements
* Students can stay updated with upcoming events and activities
* Centralized event information across all societies

### 📝 Recruitment Portal

* View active recruitment drives
* Submit applications directly through the platform
* Manage recruitment information efficiently

### 🤖 AI-Powered Society Recommendation

* Students can enter their interests, skills, and hobbies
* AI analyzes user preferences and recommends relevant societies
* Helps students discover communities aligned with their passions

### 🔐 Authentication & Authorization

* Secure JWT-based authentication
* Role-based access control
* Separate access for students, coordinators, and administrators

## 🛠️ Tech Stack

## ⚙️ Installation

### Clone the repository

```bash
git clone <repository-url>
cd SocietyHub
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
